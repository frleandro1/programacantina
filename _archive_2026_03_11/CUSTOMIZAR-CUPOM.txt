🎫 GUIA - COMO CUSTOMIZAR O CUPOM DE VENDA

===================================================================
LOCALIZAÇÃO DO CÓDIGO
===================================================================

Arquivo: js/vendas.js
Função: mostrarCupom(idVenda, itens)
Linhas: ~185-220


===================================================================
ESTRUTURA DO CUPOM
===================================================================

O cupom é montado em js/vendas.js assim:

┌─ LINHA 195  Título do cupom
│            '========================================\n'
│
├─ LINHA 196  Nome da cantina/empresa
│            '         PROGRAMA CANTINA\n'
│
├─ LINHA 197  Separador
│            '========================================\n'
│
├─ LINHA 198  Número de venda
│            'Venda Nº: ${idVenda}\n'
│
├─ LINHA 199  Data e hora
│            'Data: ${data}  Hora: ${hora}\n'
│
├─ LINHA 200  Separador
│            '========================================\n\n'
│
├─ LINHA 201  Título PRODUTOS
│            'PRODUTOS\n'
│
├─ LINHA 202  Separador de produtos
│            '----------------------------------------\n'
│
├─ LINHA 206-207  LOOP dos itens
│            (nome, quantidade, preço, subtotal)
│
├─ LINHA 210  Separador
│            '========================================\n'
│
├─ LINHA 211  Valor total
│            'TOTAL: R$ ${total.toFixed(2)}\n'
│
├─ LINHA 212  Separador
│            '========================================\n\n'
│
├─ LINHA 213  Mensagem final
│            '    Obrigado pela preferência!\n'
│
└─ LINHA 214  Separador final
             '========================================\n'

─────────────────────────────────────

Após a data (linha 199), adicione:

OPÇÃO A - Número de caixa/vendedor:
  cupom += `Vendedor: João Silva\n`;

OPÇÃO B - Número do caixa:
  cupom += `Caixa: 01\n`;

OPÇÃO C - Código da venda:
  cupom += `Código: VND-${idVenda}\n`;

OPÇÃO D - Cupom fiscal:
  cupom += `NFC-e: 123456789\n`;

5. EXEMPLO COMPLETO - CUPOM PERSONALIZADO
────────────────────────────────────────────

Copie este código e substitua a função mostrarCupom():

function mostrarCupom(idVenda, itens) {
  const modal = document.getElementById('cupomModal');
  const preview = document.getElementById('cupomPreview');
  
  const now = new Date();
  const data = now.toLocaleDateString('pt-BR');
  const hora = now.toLocaleTimeString('pt-BR');
  
  const total = itens.reduce((sum, c) => sum + c.preco * c.qtd, 0);
  
  // CUSTOMIZAÇÃO: Começar aqui
  let cupom = '';
  cupom += '========================================\n';
  cupom += '    🎭 CANTINA DO BAIRRO 🎭\n';  // ← MUDE AQUI
  cupom += '========================================\n';
  cupom += `Cupom Nº: ${idVenda}\n`;
  cupom += `Data: ${data} às ${hora}\n`;
  cupom += `Operador: João Silva\n`;  // ← NOVO
  cupom += '========================================\n\n';
  cupom += 'ITENS VENDIDOS\n';  // ← MUDE AQUI
  cupom += '----------------------------------------\n';
  
  itens.forEach(c => {
    const subtotal = c.preco * c.qtd;
    cupom += `${c.nome}\n`;
    cupom += `   ${c.qtd} unidades x R$ ${c.preco.toFixed(2)} = R$ ${subtotal.toFixed(2)}\n\n`;  // ← MUDE PARA "unidades"
  });
  
  cupom += '========================================\n';
  cupom += `TOTAL A PAGAR: R$ ${total.toFixed(2)}\n`;  // ← MUDE AQUI
  cupom += '========================================\n\n';
  cupom += 'Muito obrigado pela sua compra!\n';  // ← MUDE AQUI
  cupom += 'Volte sempre!\n';  // ← NOVO
  cupom += '========================================\n';
  // FIM DA CUSTOMIZAÇÃO
  
  preview.textContent = cupom;
  modal.classList.add('show');
}


===================================================================
VARIÁVEIS DISPONÍVEIS
===================================================================

Na função mostrarCupom(), você tem acesso a:

- idVenda           : Número da venda (ex: 1, 2, 3...)
- itens             : Array com produtos vendidos
- now               : Data e hora atual
- data              : Data formatada (ex: "05/03/2026")
- hora              : Hora formatada (ex: "14:30:45")
- total             : Valor total da venda

Para cada item do cupom:
- c.nome            : Nome do produto
- c.qtd             : Quantidade vendida
- c.preco           : Preço unitário
- subtotal          : Quantidade × Preço


===================================================================
COMO APLICAR AS MUDANÇAS
===================================================================

1. Abra o arquivo: js/vendas.js

2. Encontre a função mostrarCupom() (linha ~185)

3. Faça as alterações que deseja nas linhas do cupom

4. Salve o arquivo (Ctrl+S)

5. Recarregue a página vendas.html no navegador (F5 ou Ctrl+F5)

6. Faça uma venda de teste e veja o novo cupom!

===================================================================
DICAS IMPORTANTES
===================================================================

✓ Use \n para quebra de linha
✓ Use ` ${variavel} ` para inserir valores dinâmicos
✓ Mantenha o cupom com ~40 caracteres de largura (padrão de impressora)
✓ Não deixe linhas em branco desnecessárias (desperdiça papel)
✓ Teste sempre antes de usar em produção
✓ Crie backup do arquivo antes de editar
