# Scripts do Projeto

Este diretório contém scripts essenciais para a inicialização e manutenção do sistema Cantina.

## Scripts Disponíveis

- **INICIAR_CANTINA.bat**: Script principal para iniciar todo o ambiente (Back-end, Front-end e Banco de Dados).
- **INICIAR-MYSQL.bat/ps1**: Scripts específicos para inicializar o serviço do MySQL.
- **PARAR-PROGRAMA.bat**: Finaliza de forma segura todos os processos relacionados ao sistema.

## Como usar
- No Windows, basta dar um duplo clique nos arquivos .bat.
- Scripts .ps1 podem ser executados via PowerShell.
