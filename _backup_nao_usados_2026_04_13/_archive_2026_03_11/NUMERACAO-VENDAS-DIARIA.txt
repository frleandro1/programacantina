📋 NUMERAÇÃO DE VENDAS DIÁRIA - DOCUMENTAÇÃO

RESUMO DO SISTEMA
===================================================================

✅ IMPLEMENTADO: Sistema de numeração sequencial de cupons que reseta
diariamente. Cada venda recebe um número 1, 2, 3... até o final do 
dia, quando reseta para 1 no dia seguinte.

EXEMPLO:
  05/03/2026 → Venda #1, #2, #3... (recompensa diária)
  06/03/2026 → Venda #1, #2, #3... (novo dia, novo contador)

===================================================================
COMO FUNCIONA
===================================================================

ANTES (antigo):
  Cupom #1 = ID_VENDA (ex: 42)  ← Número alto, sem relação com dia
  Cupom #2 = ID_VENDA (ex: 43)
  
DEPOIS (novo):
  05/03 → Cupom #1, #2, #3, #4...
  06/03 → Cupom #1, #2, #3...    ← Reseta no novo dia!

PROCESSO TÉCNICO:
  1. Usuário clica em "Finalizar Venda"
  2. API consultaMAX(numero_venda_dia) WHERE DATE(data_hora) = HOJE
  3. Calcula: numero_novo = MAX + 1 (ou 1 se não houver)
  4. Insere venda com numero_venda_dia = numero_novo
  5. Retorna numero_venda_dia no JSON
  6. JS exibe no cupom: "Venda Nº: 3" (por exemplo)

    id_venda,

    TIME(data_hora) as hora,

===================================================================
TROUBLESHOOTING
===================================================================

PROBLEMA: Cupom ainda exibe números muito altos
SOLUÇÃO: 
  - Recarregue a página vendas.html (Ctrl+F5)
  - Verifique se JS está atualizado
  - Cheque console (F12) para erros

PROBLEMA: Números sempre começam em 1, mesmo dias diferentes
SOLUÇÃO:
  - A data pode estar em fuso horário diferente
  - Verifique timezone do servidor MySQL
  - Use: SELECT NOW(), CURDATE();

PROBLEMA: Erro "numero_venda_dia não encontrado"
SOLUÇÃO:
  - Coluna não foi criada no banco
  - Execute script: config-numeracao-vendas.php?action=criar_campo
  - Verifique se o ALTER TABLE funcionou

PROBLEMA: Venda criada mas sem número
SOLUÇÃO:
  - Função obterNumeroVendaDia retorna 1 por padrão
  - Verifique erros em: error_log do PHP
