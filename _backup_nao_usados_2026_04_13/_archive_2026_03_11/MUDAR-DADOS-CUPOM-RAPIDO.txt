===================================================================
3 FORMAS DE CUSTOMIZAR O CUPOM
===================================================================

1️⃣ INTERFACE VISUAL (MAIS FÁCIL) ⭐
─────────────────────────────────────

Não precisa editar código!

ACESSE: http://localhost/Cantina/customizador-cupom.html

O quê você pode fazer:
✓ Mudar nome da cantina
✓ Adicionar vendedor/operador
✓ Adicionar número do caixa
✓ Mudar "Venda Nº" para outro rótulo
✓ Customizar mensagens finais
✓ Mudar separadores
✓ Ver pré-visualização em tempo real
✓ Aplicar templates prontos

Como usar:
1. Abra a página no navegador
2. Preencha os campos que deseja
3. Veja a pré-visualização ao lado
4. Está bom? Continue para salvar (próximo passo)


2️⃣ SALVAR CUSTOMIZAÇÕES NO BANCO (APLICAR PARA TODOS)
───────────────────────────────────────────────────

AINDA NA PÁGINA customizador-cupom.html:

1. Configure tudo como deseja
2. Clique em "EXPORTAR CONFIGURAÇÃO"
3. Um arquivo JSON será baixado
4. Envie o arquivo para o administrador
5. O administrador executa: 
   api/cupom-config.php?action=salvar
   (com os dados do JSON no POST)

RESULTADO: Todos os cupons gerados usarão a nova configuração!


3️⃣ EDITAR CÓDIGO DIRETAMENTE (MAIS DIFÍCIL)
──────────────────────────────────────────

Para usuários avançados que sabem JavaScript/PHP:

ARQUIVO: js/vendas.js
FUNÇÃO: mostrarCupom()
LINHAS: ~185-220

EDITAR ASSIM:

┌─ Linha 196: Nome da cantina
│  cupom += '         PROGRAMA CANTINA\n';
│  ↓
│  cupom += '         MEUS DADOS AQUI\n';
│
├─ Linha 198: Rótulo do número
│  cupom += `Venda Nº: ${idVenda}\n`;
│  ↓
│  cupom += `Cupom Nº: ${idVenda}\n`;
│
├─ Linha 201: PRODUTOS
│  cupom += 'PRODUTOS\n';
│  ↓
│  cupom += 'ITENS VENDIDOS\n';
│
└─ Linha 213: Mensagem final
   cupom += '    Obrigado pela preferência!\n';
   ↓
   cupom += '    Agradeço pela compra!\n';

Depois: Salve (Ctrl+S) → Recarregue vendas.html → Teste!

TEMPLATES PRONTOS

1. SIMPLES - Cupom minimalista (ideal para impressoras antigas)
2. COMPLETO - Cupom com mais dados (vendedor, operador, etc)

Como usar:

3. Veja a pré-visualização mudar
4. Faça ajustes se necessário
5. Está bom? Exporte a configuração


===================================================================
VALIDAÇÃO DE MUDANÇAS
===================================================================

PARA CONFIRMAR QUE TUDO FUNCIONOU:

1. Customize o cupom em: customizador-cupom.html
2. Abra: vendas.html
3. Faça uma venda de teste
4. No cupom exibido, procure:
   ✓ Seu nome correto?
   ✓ Sua mensagem apareceu?
   ✓ Separadores corretos?
5. SIM? Pronto! Está funcionando!
6. NÃO? Verifique:
   - Página está recarregada (F5)?
   - Arquivo js/vendas.js foi salvo?
   - Cache do navegador (Ctrl+Shift+Delete)?

===================================================================
TROUBLESHOOTING
===================================================================

PROBLEMA: Customizações não aparecem
SOLUÇÃO:
  1. Recarregue: Ctrl+F5 (força recarregar cache)
  2. Verifique se vendas.js foi salvo
  3. Feche completamente o navegador
  4. Abra novamente

PROBLEMA: Caracteres estranhos aparecem
SOLUÇÃO:
  1. Verifique se é um caractere especial/emoji
  2. Copie de um site confiável

PROBLEMA: Cupom aparece truncado na impressora
SOLUÇÃO:
  1. Reduza o tamanho do separador
  2. Diminua a fonte (editar CSS em vendas.html)
  3. Remova mensagens desnecessárias

PROBLEMA: Não sei editar arquivo js/vendas.js
SOLUÇÃO:
  1. Use o customizador visual (customizador-cupom.html)
  2. Solicite ajuda ao seu T.I
  3. Consulte a documentação completa
