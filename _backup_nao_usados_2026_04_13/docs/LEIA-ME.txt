## 🚀 Para Colocar em Funcionamento

### PASSO 1: Instalar Servidor Web
Escolha UMA opção:

**A) XAMPP (Recomendado)**
- Baixe: https://www.apachefriends.org/pt_BR/
- Instale normalmente
- Copie pasta para `C:\xampp\htdocs\`

**B) WampServer**
- Baixe: http://www.wampserver.com/
- Instale
- Copie pasta para `C:\wamp64\www\`

**C) PHP Built-in (Se tiver PHP)**
```
php -S localhost:8000
```

### PASSO 2: Verificar Banco de Dados
Seu banco `programa_cantina` deve ter as 4 tabelas:
- usuarios
- produtos
- vendas
- movimentacoes

Se não tiver, execute:
```
http://seu-servidor/programa-cantina/install.php
```

### PASSO 3: Fazer Login
```
http://seu-servidor/programa-cantina/login.html
```

**Credenciais:**
- Usuário: `admin`
- Senha: `admin123`

### PASSO 4: Usar o Dashboard
- 📊 **Dashboard** - Ver estatísticas
- 📦 **Produtos** - Gerenciar produtos (CRUD)
- 💰 **Vendas** - Registrar e consultar vendas

## 🐛 Solução de Problemas

### Erro: "Arquivo não encontrado"
→ Você abriu pelo `file://` em vez de `http://`
→ Use um servidor web (XAMPP, WampServer, etc.)

### Erro: "Conexão recusada"
→ O MySQL não está rodando
→ Inicie MySQL no seu servidor web

### Erro: "Tabelas não existem"
→ Execute `install.php`
→ Ou execute o `schema.sql` no phpMyAdmin

### Login não funciona
→ Verifique se o banco `programa_cantina` existe
→ Verifique `db/config.php` com as credenciais certas
